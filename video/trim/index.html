Trim Video

Overview

Trim Video cuts a clip from a longer file without re-encoding the whole video when possible. Pick start and end points on a timeline, preview the range, and export a shorter file that keeps the original container and codecs.

How to trim a video

Follow these steps in your browser — nothing is uploaded to a server.

  • Import a video file from your device.
  • Drag the timeline handles or use frame controls to set the start and end points.
  • Preview the selected range, then export.
  • Save the trimmed file locally when processing finishes.

Keep source format

MeiTools tries to preserve the source container, video codec, and audio track. Only the selected time range changes. If a clean cut is not possible at the exact frame boundaries, a short segment near the edges may be re-encoded while the rest stays copied.

Local processing

All decoding, trimming, and encoding runs on your device. Files are not sent to a cloud service. Large or long videos may use significant memory — use a desktop browser when possible and watch the risk notice before exporting.

FAQ

  • Which formats are supported? Common MP4, WebM, and MOV files usually work. Unsupported codecs show an error at import.
  • Does trimming reduce quality? When stream copy succeeds, quality matches the source. Re-encoded edge segments use conservative settings only where needed.
  • Can I trim on a phone? Yes, but long or 4K files are safer on desktop.
